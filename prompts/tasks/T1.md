Add a sort order to Krypta's vault list screen.

Requirements:
1. The user can choose between two orders: "Name" (entry title, A to Z, case-insensitive) and "Recently updated" (most recent `updatedAt` first). The default is Name.
2. The control lives on the vault list screen (for example in its top bar or next to the search field) and is built with the design system components.
3. The choice survives app restarts. Store it locally on the device, outside the vault database and outside backups.
4. Search keeps working: the filtered list follows the chosen order.
5. Put the ordering logic in a pure, unit-testable function in package `it.gr.krypta.vault.ui.list`:
   - `enum class VaultSortOrder { Name, RecentlyUpdated }`
   - `fun sortVaultEntries(entries: List<VaultEntry>, order: VaultSortOrder): List<VaultEntry>`
   - Entries that compare equal keep their original relative order.
6. Add the user-visible strings in English and Italian.

When you are done, the app must build: run `./gradlew assembleDevDebug` from the Krypta directory. Do not commit.
