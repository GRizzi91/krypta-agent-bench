Let the user pin vault entries so that they stay at the top of the list.

Requirements:
1. `VaultEntry` gets a new property `val pinned: Boolean = false`.
2. The vault list shows pinned entries first; within each group (pinned, not pinned) the existing order is kept.
3. The entry detail screen has a pin/unpin action; the change is saved immediately.
4. The flag is stored in the Room database. Add a migration so that existing vaults keep all their data and their entries start unpinned; bump the database version.
5. Backups carry the flag. Restoring a backup created before this change must still work, with every entry unpinned.
6. The home screen widget also lists pinned entries first.
7. Add the user-visible strings in English and Italian.

When you are done, the app must build: run `./gradlew assembleDevDebug` from the Krypta directory. Do not commit.
