Add a password generator to the vault entry editor.

Requirements:
1. Next to each code's value field in the editor there is a "Generate" action that fills the field with a new random password.
2. Before generating, the user can set the length (8 to 64, default 20) and whether to include symbols (default on), in a bottom sheet or dialog built with the design system components.
3. Implement the generator as a pure function in package `it.gr.krypta.vault.ui.editor`:
   - `fun generatePassword(length: Int, includeSymbols: Boolean, random: java.util.Random = java.security.SecureRandom()): String`
   - It throws `IllegalArgumentException` when `length` is outside 8..64.
   - The result has exactly `length` characters and contains at least one lowercase letter, one uppercase letter and one digit, plus at least one symbol when `includeSymbols` is true (and no symbol when it is false).
   - It never uses the ambiguous characters 0, O, o, 1, l, I.
   - Symbols are drawn from `!@#$%^&*()-_=+[]{};:,.?`
4. Add the user-visible strings in English and Italian.

When you are done, the app must build: run `./gradlew assembleDevDebug` from the Krypta directory. Do not commit.
